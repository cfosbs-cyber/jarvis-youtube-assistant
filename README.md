# Jarvis AI YouTube Assistant

A Jarvis-style AI assistant designed for a YouTube creator.

Features:
- Brainstorm video ideas
- Generate titles, hooks, descriptions, and tags
- Draft YouTube scripts and thumbnail concepts
- Summarize channel strategy and upload plans
- Provide AI-powered assistant replies for comments and content planning

## Stack
- Next.js
- TypeScript
- OpenAI API

## Setup
1. Install dependencies:
   npm install
2. Create a `.env.local` file with:
   OPENAI_API_KEY=your_key_here
3. Start the app:
   npm run dev
4. Open http://localhost:3000

## Notes
This is a ready-to-extend MVP. It is designed to help your YouTube workflow and can be expanded with analytics integrations, Google auth, and a database.
